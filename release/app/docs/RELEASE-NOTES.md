# Release notes — 0.1.0-rc.1

This is the initial separate Research Replication Toolkit release candidate. It adds a local workflow for catalog discovery, strict dataset registration, immutable versioned protocol freezing, fixed method/baseline execution, descriptive comparison, private evidence verification, and aggregate JSON/HTML export.

The native profiles use qualification records for `D0001/C0081-03` and `D0007/C0322-01` from the verified shared foundation. The numerical profiles add fixed OLS, development-mean, zero-predictor, and equivalent-baseline methods, with prespecified synthetic controls and a bounded custom-data contract. No new source-paper replication claim is introduced.

The workflow preserves separate execution, implementation-check, comparison, and source-claim fields. It retains unsuccessful runs, explicit supersession with reasons, deterministic repetition limits, cancellation, and recovery without reexecuting missing processes. Public reports exclude dataset labels, row-level outcomes, and raw predictions.

PC-Winter remains blocked. C0322-02 is duplicate evidence, not an independent result. Original deliveries, original notes, shared-foundation releases, the workbench, and the coding-agent platform remain separate and protected.

The release candidate requires the declared Windows/Python/NumPy/.NET environment and does not download dependencies, contact a model, or execute arbitrary user code. Consult RELEASE-DECISION.json and the acceptance report in the surrounding release package for tested outcomes, exact gate decisions, command records and preservation checks.
