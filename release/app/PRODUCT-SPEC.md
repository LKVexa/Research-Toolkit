# Research Replication and Benchmarking Toolkit

This separately versioned local product lets a researcher discover a qualified experiment, validate and register data, freeze a versioned protocol, execute a fixed method and baseline, compare raw observations, verify the evidence and export an aggregate report. It uses the immutable shared foundation and has no dependency on workbench or coding-agent state or source files.

The first release exposes eight fixed experiment profiles and ten sample protocols. Five native sample comparisons replay two selected source components, D0001/C0081-03 and D0007/C0322-01. Five numerical sample comparisons validate product-authored OLS, mean, zero and equivalent-baseline rules against three analytical datasets. Registered custom numerical datasets can use the same fixed rules with MSE or MAE. General plugin execution and paper-scale replication are outside this release's scope.

The frozen foundation retains 393 catalog entries. Three fixture capabilities exist in that foundation; two are selected for distinct toolkit bindings. D0007/C0322-02 duplicates the observations of C0322-01 and is not counted as another independent experiment. The other 390 entries remain unavailable to execution. PC-Winter remains blocked here because it is not qualified, and its historical negative findings remain unchanged.

Each result separates execution, implementation checks, comparison direction, source-claim status and evidence eligibility. Negative and inconclusive comparisons can be valid results. Failed, cancelled, interrupted or nonreproducible runs cannot publish a final positive/negative comparison. Private observations remain available for local diagnosis and are never silently deleted to improve a result.

Protocol revisions and explicit superseding runs add records with reasons. Recorded dataset and protocol contents have hash receipts. Raw process outputs and local evaluator evidence are sealed per run. Resume never restarts missing process execution; complete preserved outputs can be evaluated again, while incomplete work is retained as interrupted. Users can request a fresh run explicitly.

The supported platform is Windows with Python 3.12.14, NumPy 2.3.5 and the preserved Windows .NET Framework fixture runtime. No network, model access, resource purchase or new package installation is required. Source notes and imported metadata supply provenance, not operational authority.

Publication, scientific superiority, paper-scale training, user-written executable adapters and arbitrary external datasets beyond the documented numerical schema are excluded. Every claimed source-paper replication remains unverified unless supported by a future separately qualified experiment and evidence.
