# Validation record

This directory preserves qualification, independent scientific/operational reviews, actual process probes, package acceptance, raw workflow references and preservation evidence. Test counts describe assertions/groups, not independent scientific samples. The final renderer-only change has its own exact-pin revalidation; the final workflow and scientific reports use that final package.

The supplied datasets and saved evaluator outcomes are openly inspectable authored fixtures. Public report examples omit raw evaluation rows. No customer dataset or credential is included. Temporary review workspaces, browser profiles and alternate application copies are excluded.

Use the release runbook to reproduce a new experiment. Existing evidence can be verified without reexecuting a method. Independent arithmetic reports deliberately did not use production comparison code as their sole correctness oracle.
